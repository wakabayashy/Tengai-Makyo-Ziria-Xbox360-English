# Tengai Makyō: Ziria – Haruka Naru Jipang — Xbox 360 English Translation

An English translation project for the Japanese Xbox 360 release of **Tengai Makyō: Ziria – Haruka Naru Jipang**.

> **Current status: In development — approximately 50% of the dialogue translated.**

**Main developer: Veiga117**  
**Project publication / coordination: wakabayashy**

## About the Project

This project aims to make the Japanese Xbox 360 version of Tengai Makyō: Ziria – Haruka Naru Jipang accessible to English-speaking players.

The project is published under my name, with Veiga117 handling the actual translation and technical work.

## Translation and Editing

According to Veiga117's latest progress update, approximately **50% of the game's dialogue has been translated**.

AI assistance is being used to speed up the initial translation process. However, the translated text will not simply be inserted without review.

**Every dialogue is planned to receive a manual review before release.**

The work includes:

- English translation of the Japanese dialogue.
- Text editing and corrections.
- Manual review of every dialogue.
- Technical research and game-file investigation.
- Integration of translated content.
- Patch development and in-game testing.

Reaching 100% initial dialogue translation will not by itself mean the project is ready for release. Manual review, technical validation and playtesting will still be required.

## Optional Quality-of-Life Features

While investigating the game, Veiga117 found developer debug variables that can be used to modify certain game behaviours.

Two optional QoL possibilities have been identified:

### 1. Cutscene Skip

The original game makes its cutscenes unskippable. Veiga117 found debug variables that can force cutscenes to be skipped.

### 2. Dialogue Speed-Up

The debug research also provides a way to investigate speeding up dialogue.

These improvements are intended to be optional, so players can choose whether to use them. Their final behaviour and availability will depend on further implementation and testing.

## Technical Testing

Initial testing has already started. Some crashes have been encountered during testing and still require investigation.

The debug variables are being investigated and injected as part of the technical work before testing resumes.

No claim is being made that the current build is complete or stable.
